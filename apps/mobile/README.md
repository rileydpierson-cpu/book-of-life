# Book of Life Mobile

The active Expo app lives here in `apps/mobile/`.

Default app behavior:

- launches the cloud WebView shell at `/app?mobile=1`
- keeps the previous native Expo screens available as an in-app fallback
- uses Supabase/cloud sign-in to link phone and desktop libraries

Useful commands from the repo root:

```bash
npm run mobile:start
npm run mobile:android
npm run mobile:apk
```

The debug/release APK generated by Gradle is written under `apps/mobile/android/app/build/outputs/apk/`.
